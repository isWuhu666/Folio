用户已要求按上一轮全部建议一次性实施；沿用现有工作副本，保留之前未提交改动，不推送或发布远端。

## 设计与验收

本地优先、无需账号；现有安全边界和单文件 HTML 保留。普通用户使用 Windows 便携包，开发者使用源码。新增项目文件是带版本 manifest 的 ZIP，导入前限制文件数、解压后大小、路径、格式，并重新校验图片；不执行项目内 HTML/JS。不增加 OCR、云同步或多人协作（上一轮明确属于后续独立方向）。

- [x] Windows 便携包：冻结 Python 入口、PDF worker 子命令、随包资源、托盘运行/打开/重启/退出、可选登录自启、版本；构建脚本和 Release CI，实际构建与包内冒烟测试。
- [x] 完整项目：源文档、图片、选项、PDF 设置的 ZIP 保存/打开，跨浏览器恢复；非法包不覆盖当前工作；最近项目与快照提供显式本机保存和清除。
- [x] PDF：页码范围、真实逐页进度、真正取消进程、逐页原文/结果核对、回退页定位；不夸大语义识别或 OCR。
- [x] 导出：高清/阅读/分享图像预设、实际体积、单文件与 HTML+资源 ZIP 两种方式；打印表头、分页、公式保持完整。
- [x] 资源：缩略图、体积、使用/缺失状态、定位、替换、清理未用图；粘贴截图本地引用。
- [x] 编辑：公式模板和语法帮助、快捷键、保留中文输入、预览反向定位源段落。
- [x] 开源：MIT 项目许可证（采用宽松许可便利用户使用和贡献）、第三方材料复核、通用 README/示例截图/平台限制、贡献/安全渠道、问题模板、CI 测试和依赖检查。
- [x] 验证：新增失败用例先执行；后端/浏览器全量回归，桌面/320px 渲染检查，发行包离线冒烟；独立最终审阅。

## 分工与接口

PDF 后端负责 folio/pdf_converter.py、pdf_worker.py、http_server.py 与新增 jobs 模块和 Python 测试。保留旧 POST /api/pdf；新 POST /api/pdf/jobs?mode=&dpi=&pages= 返回 {id,token}，GET /api/pdf/jobs/{id} 带 X-Folio-Job 获取 {state,stage,completed,total,result?,error?}，POST 同路径 /cancel 真正 kill；资源有界、过期清除、同源及 token 校验。

发行负责 desktop.py、scripts、打包入口、.github、README/许可证与开发文档、相关 Python 测试；不碰 web 和 PDF 后端。

主代理负责 web 模块/界面、项目 ZIP、导出配置、资源/编辑/核对与浏览器测试和集成。

## 风险与验证重点

1. 冻结后 sys.executable 不是 Python：专用 --pdf-worker 分派、资源路径及独立包运行验证。
2. 导入 ZIP 炸弹/路径穿越/活动内容：解压前后双重界限、白名单 manifest、图片重验证和原子替换。
3. 异步任务取消/切换/导入竞态：版本标识、取消后台进程、旧回调不得覆盖新工作。
4. 压缩不能污染原始项目图像，默认高清保持原图；只对明确选择的输出优化。
5. 浏览器草稿/历史存在隐私与容量边界，清除必须同时涵盖新增历史。
