# 安卓本地应用实施与验收

用户要求在现有 Windows 便携包之外提供安卓可安装版本。沿用本地处理、无账号和独立HTML/项目文件，新增APK，不要求手机连接电脑或本机8765服务。不发布应用商店、不上传用户文件。

## 实施方案

- 原生 Android Activity + 受限 WebViewAssetLoader 加载随包工作台；只给受信任主框架提供文件保存消息通道，所有外部请求/导航阻断。无网络权限、无全盘读写权限；系统文件选择器导入和创建文档导出。
- 手机PDF由本地PDF.js worker解析并渲染，采用手机资源上限，提供逐页进度、取消、原页核对；简单文本可保守重排，复杂页回退并明确标记，不宣称OCR或与Windows解析结果完全相同。
- Markdown/公式/图片/草稿/快照/项目/HTML/ZIP共用现有逻辑，导出走系统保存位置选择器；安卓图片选择替代不可靠的目录导入，打印走原生打印服务。
- Android 8+，需要现代 Android System WebView，旧内核明确提示更新；APK使用开发签名用于侧载试用，正式发行需维护者私钥签名，密钥不入库。

## 分工接口

Native 构建负责 android/**、scripts/build-android.ps1、安卓CI及SDK/Gradle准备。主代理负责web、PDF.js、资源准备和浏览器回归。

受限消息桥命名 FolioAndroid，只接受 https://appassets.androidplatform.net 主框架。JS postMessage(JSON) 发送 {id,op:'begin',name,mime,size}，用户选择保存位置后回 {id,ok:true}；逐块{ id,op:'chunk',data:base64 }每块收到确认再发送；{id,op:'finish'}关闭并确认，{id,op:'abort'}取消并清理部分输出。失败回 {id,error,cancelled?}。op:'print' 使用原生WebView打印。单任务、大小/块长/序列校验，权限仅来自系统选择器；文档iframe不得调用桥。

- [x] 原生APK实际构建、签名检查、清单权限和随包资源检查。
- [x] 安卓模拟消息桥覆盖导出成功、取消、错误及主机版回归。
- [x] 本地PDF引擎涵盖文字/扫描/公式/旋转/选页/取消/限额；禁联网仍能排版和转换。
- [x] 手机窄屏、安全区和原PDF预览适配，项目格式可与Windows互通；键盘及不同厂商仍需实体手机扩展验收。
- [x] 专用 API 37 模拟器完成真实安装与系统文件选择、项目保存、打印冒烟；未使用实体手机。

交付与证据见 [Android 1.2.0 验收记录](../../android-validation-2026-10-22.md)。

## 风险

1. 手机上的内存不足：较低PDF输入/选页/像素限额、逐页释放画布、可取消worker。
2. WebView文件与桥越权：限定本地来源和主框架、系统授权URI、流式限额与状态机，预览继续禁止脚本。
3. APK能构建但不同手机内核差异：能力检测、最低系统/内核说明，实际设备验收边界单独记录。
