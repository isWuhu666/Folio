# 第二轮用户测试修复记录

本轮针对基线 `a9e70b4` 的用户测试反馈。将六项重复复现的问题与体验建议、功能机会分开处理；未修改外部审计副本或原始证据。

## 已实施

| 报告项 | 最终行为 |
| --- | --- |
| R01 草稿恢复陷阱 | 写入前校验正文及可恢复资源，拒绝超限版本并保留上一份有效草稿；界面报告自动保存失败，未保存修改继续受离开页面保护。旧非法文本记录可独立救援下载，最多 20 MiB，不依赖资源校验，不删除原记录 |
| R02 异步保存错配 | 项目与快照在首次异步操作前捕获内容、名称、revision；文件名与归档一致，完成提示说明保存版本，期间继续编辑则提示尚有新修改 |
| R03 多文档输入 | 普通导入拒绝多份主文档并具名说明，当前工作保留；仍可一次导入主文档与多张图片 |
| R04 不支持的输入 | 全部不支持时明确拒绝；混合输入处理受支持文件，并在完成状态列出未处理名称 |
| R05 编码提示 | 严格 UTF-8 解码及 BOM UTF-16 LE/BE；解码失败在替换当前工作前拒绝，提示先将原文件转为 UTF-8。未猜测 GBK，原始磁盘文件不变 |
| R06 SVG 静默损失 | 清理实际移除的节点、属性产生非阻塞警告，提醒核对与转 PNG；普通 SVG 不误报，非法图像仍拒绝项目读写。修复索引诊断使用明确资源键，避免嵌套目录被拼接两次 |
| U01、U10 快照 | 删除单项/全部已有快照前确认数量；显示标题、正文摘要、精确字节数及版本。既有清空防复活机制保持 |
| U02 工作区 | 可退出的专注模式收起介绍与次要工具，把高度留给正文和预览 |
| U03、U04 输出反馈 | 手机设置页显示格式、预设、打印；导出按钮旁提供问题数及原因定位；公式提示包含美元价格转义例子 |
| U05 资源修复 | 缺图列表提供定位和选择图片修复，复用原有校验及版本保护 |
| U06 恢复备份 | 恢复对话框增加完整 `.folio` 备份，保留原文下载；严格完整备份失败时仍可尝试文本救援，不自动丢弃草稿 |
| U07 命名 | 新建未命名笔记提供“使用标题命名”，需主动点击；不静默重命名导入文档或项目 |
| U08 触控 | 手机主要按钮最小高度 44px，关键控件与字号增大；测试窄屏和 CSS 放大文字，无横向溢出 |
| U09 帮助 | 界面可随时打开三步指南，解释成品、完整项目、本机草稿和快照的区别 |

## 验证方法

新增回归先在旧实现观察到预期失败，再实施修复。重点读取实际 IndexedDB 数据、下载文本及解码 `.folio`，不只检查成功文案。独立审查另发现嵌套 SVG 修复路径问题，已补失败测试并修正。

新增浏览器测试分别在 `draft-safety.spec.mjs`、`save-snapshots.spec.mjs`、`input-experience.spec.mjs`、`svg-feedback.spec.mjs`。既有慢导入测试的屏障从 `File.text()` 改到严格解码实际使用的 `File.arrayBuffer()`，保留旧导入不能覆盖新导入的行为断言。

## 范围及剩余边界

- F01 静态任务列表、F02 Mermaid、F03 PDF 搜索、F04 批量路径映射是功能机会，本轮没有冒充缺陷或宣称已实现。Mermaid 还需要独立的安全与复杂度约束。
- U06 的恢复前预览、U10 的自定义快照备注未新增；本轮用完整备份与内容摘要处理主要数据保护和辨识需求。
- 文本救援上限 20 MiB；超出时请保留浏览器数据。完整项目备份仍严格校验，不会为救援放开任意资源或活动内容。
- Android 系统 PDF 选择器返回阶段的上一轮失败仍未定位；本轮构建、浏览器平台测试不能替代其原生全流程验收。未宣称实体手机、最低 Android/WebView、系统级字体放大或屏幕阅读器全流程通过。
- 本轮 Windows/Android 验证产物单独保存在 `artifacts`，不覆盖旧版本公开发行附件。源码改动不代表已下载的历史便携包/APK 自动更新。
